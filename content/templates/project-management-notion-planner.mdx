## What you get

A project system where the six dashboards talk to each other. A task belongs to a project, the project belongs to a client, the client has a budget, and the budget updates as expenses are logged. You set it up once and then just work.

### Projects

Plan and run projects from a single workspace with linked views for everything attached to them.

- Kanban board by status
- Timeline and Gantt view
- Project brief pages
- Linked tasks, budget, client and team

### Tasks

- Tasks by priority
- Tasks by status
- Tasks by project
- Overdue tasks
- Task calendar

### Clients

- Client directory
- Projects per client
- Contacts and notes
- Status and history

### Meetings

- Meeting notes with agendas
- Action items linked to tasks
- Attendees and decisions
- Meeting calendar

### Finances

- Project budgets
- Expense log
- Income tracking
- Budget vs actual

### Team

- Team directory with roles
- Workload by member
- Responsibilities per project

## Why it works

**It scales down as well as up.** Solo freelancers can ignore the team dashboard entirely and still get a complete client and project system.

**Nothing is duplicated.** Because the databases are related, updating a deadline once updates it everywhere it appears.

**It is fully unlocked.** Change statuses, add fields, rebuild the views. The structure is a starting point, not a cage.

1. Complete checkout. One payment, no subscription.
